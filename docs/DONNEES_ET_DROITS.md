# Données, modèles et droits

Le dépôt est destiné au partage du logiciel et des explications du groupe. Aucune licence de redistribution du code du groupe n’est fixée automatiquement. Consulter le groupe avant de rendre le dépôt public ou de choisir une licence.

Les jeux publics conservent leurs conditions : [RailSem19](https://www.wilddash.cc/download), [annotations ego-path](https://github.com/irtrailenium/train-ego-path-detection), [RAIL-BENCH](https://www.mrt.kit.edu/railbench/track_detection). Télécharger via leurs sources et autorisations ; ce dépôt ne les redistribue pas.

Les bibliothèques PyTorch, segmentation_models_pytorch, Albumentations, OpenCV, Pillow, Matplotlib et les autres dépendances gardent leurs licences. Le code les importe ; il ne copie pas leurs sources ici.

Restent hors versionnement : vidéos/images réelles, annotations, GPS/GPX, documents fournis par les partenaires, checkpoints, environnements Python, historiques de téléchargement et liens privés Drive. Les graphes publiés sont des résultats agrégés générés par le projet, sans images source ni coordonnées GPS.

La copie préparée pour GitHub conserve le code de calcul. Les scripts de rapports et audits propres au rangement du Mac ne sont pas inclus. Les chemins privés ont été retirés ; les ancrages GPS réels ont été remplacés par une entrée CSV locale requise, sans valeurs inventées. Les protocoles historiques attendent leurs données et sorties intermédiaires.
